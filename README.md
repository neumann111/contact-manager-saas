# Contact Manager SaaS

A production-grade MERN Contact Manager application built with modern software engineering practices.

## Tech Stack

- React
- Vite
- TypeScript
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary
- Docker

## Features

- Secure Authentication
- Contact Management
- Categories
- Favorites
- Dashboard Analytics
- Profile Management
- Image Upload
- CSV Import
- CSV Export
- PDF Export
- Advanced Search
- Pagination
- Filtering
- Dark Mode
- Responsive Design
